# Unity of Effect

**Concept:** unity-of-effect · **Layer:** craft
**Used by:** `narrative-architect` agent, `adversarial-reader` agent

## Definition
Poe's principle, most binding on short forms: decide the single intended effect on the reader
first, then subordinate *every* element — incident, image, sentence, length — to it. Nothing
that does not serve the effect earns its place; the ideal short story can be read in one sitting
so the effect is not diluted by interruption. This is the craft counterpart of the reader
contract's `desired_affect`: the effect is chosen, and the work is composed toward it (often
backward, from the intended close).

## Use when
Judging scene necessity and global coherence of a short work; setting or checking `desired_affect`.

## Diagnostic questions
- What single effect should the reader leave with? Is it named in the brief?
- Does each scene *serve* that effect, or dilute it with a different tone/aim?
- If I composed backward from the final image, would this element still be here?
- Is length itself working against the effect (padding that breaks the single sitting)?

## Failure modes
- Tonal digressions that spend the reader's attention on a different feeling.
- "Everything and the kitchen sink" — subplots a short form cannot pay off.
- An ending that lands a different effect than the one built toward.

## Conflicts with
Deliberate polyphony / ambiguity — some works want multiple, held-in-tension effects; record
that as the contract so this doesn't misfire ([[suspense-surprise-curiosity]]).
