---
name: retrospective
description: Converts repeated, evidenced writing-process failures into bounded improvement proposals and regression tests.
---
1. Gather failures from critique reports, human feedback, and rejected promotions.
2. Cluster repeated root causes; ignore one-off taste disagreements.
3. For each proposed process change, write the eight fields required by `constitution/change-policy.md`.
4. Add a regression fixture that would have caught the failure.
5. Run blind before/after comparisons.
6. Never edit the constitution or global rubric without human approval.
