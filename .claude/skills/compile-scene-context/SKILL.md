---
name: compile-scene-context
description: Builds a minimal, task-specific context bundle for drafting or auditing one scene.
---
Run `python3 scripts/compile_scene_context.py <project-dir> <scene-id>`. Inspect the generated bundle in `.runs/`. Add only missing relevant canon. Do not paste the whole project into context. The bundle must include scene spec, participating characters, current known facts, relevant world rules, nearby promises, discourse constraints, and style profile.
