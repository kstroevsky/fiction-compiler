---
name: triple-audit
description: Runs independent hard, literary, and defaultness audits on scene candidates and produces evidence-grounded critique files.
---
1. Run `python3 scripts/validate_workspace.py`.
2. Delegate hard continuity review to the continuity auditor.
3. Delegate character intentionality review to the character simulator.
4. Delegate prose review to the style editor only if structure passes.
5. Delegate cliché/predictability review to the adversarial reader.
6. Require exact evidence and repair-layer labels in every finding.
7. Anonymize candidates and reverse order for at least one pairwise comparison.
8. Write separate critique JSON files. Preserve disagreement.
