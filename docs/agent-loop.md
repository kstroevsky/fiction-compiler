# Agent Loop

## Stage 0 — Contract
Resolve audience, form, genre promise, theme question, tone boundaries, desired affect, length, viewpoint, and originality constraints.

## Stage 1 — Divergence
Generate a premise set using orthogonal mutation operators: change desire, cost, social structure, causal mechanism, moral dilemma, narrator access, or genre expectation. Do not create cosmetic paraphrases.

## Stage 2 — Structural simulation
Construct characters, world invariants, event graph, knowledge states, and possible failure paths. Simulate whether each major action follows from beliefs, desires, constraints, and available information.

## Stage 3 — Hierarchical planning
Plan book → act/movement → sequence → chapter → scene. Keep plans revisable; do not freeze detail earlier than needed.

## Stage 4 — Candidate drafting
For a scene, compile only relevant context. Produce 2–4 candidates with declared strategic differences.

## Stage 5 — Triple audit
Run hard, literary, and defaultness audits independently. Require evidence spans and repair-layer labels.

## Stage 6 — Blind selection
Anonymize candidates, reverse order for one judge, compare pairwise, and retain a Pareto set when trade-offs are real.

## Stage 7 — Repair
Repair the lowest responsible layer. Recompile dependent artifacts and rerun audits.

## Stage 8 — Promotion
Human or configured gate accepts a candidate. Copy it to manuscript, apply a state delta, update promises and knowledge, then validate globally.

## Stage 9 — Periodic global audit
At chapter/act boundaries, check long-range causality, arc movement, revelation schedule, motif evolution, pacing, and style drift.

## Stage 10 — Learning
Turn repeated, evidenced failures into regression cases and proposed process changes. Do not autonomously rewrite the constitution.
